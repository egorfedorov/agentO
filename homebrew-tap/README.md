# Homebrew Tap for Agent-O

```bash
brew tap egorfedorov/agento https://github.com/egorfedorov/agentO.git --force-auto-update
brew install agento
```

Then run:
```bash
agento
```

## About

Agent-O is an ASCII desktop companion for Claude CLI & Codex CLI. A native macOS floating Tamagotchi that helps you code, learns, evolves, and keeps you company.
