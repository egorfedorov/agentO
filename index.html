Project Vision

Build a specialist AI pet, not a generic bot

Agent-O is designed as a skill economy: your pet learns from your real daily prompts and becomes stronger in your domain. Strong specialist pets get rented by other users for focused tasks.

1) Train by Real Work

Each prompt in Claude/Codex usage contributes to pet learning signals: domain, patterns, quality, and consistency.

2) Build Domain DNA

Pets become different: Stake Engine game-dev pet, art-prompt pet, frontend UX pet, debugging pet, and more.

3) Publish & Rent

Owners list pets with /rent publish. Renters pick by specialization and rental history.

4) Earn from Expertise

Rental demand should follow specialization quality. Better domain pets become more valuable in the marketplace.

Direction: skill-based pet economy with transparent profiles, renter trust signals, and payout mechanics.

New in v6.2.0

Big social update: fight, rent, train

Agent-O is now a multiplayer coding companion with tactical duels, a public pet rental market, and a real training loop for your pet's memory.

⚔ Tactical Duel System

Battle flow is now challenge-based. Opponent must accept, then both players pick attack and defense zones (head/body/legs).

/battle username -> /accept username -> /move head body

🏢 Pet Marketplace Rentals

Publish your pet listing, rent other pets, track active and completed rentals, and view everything on a web marketplace.

🧠 Training Dashboard

See training score, prompt quality, learned patterns, and continuously improve your pet with explicit memory training.

/training | /train "I prefer concise patch plans"
Features

Everything your coding companion needs

Agent-O is packed with features that make coding more fun, productive, and social.

🤖

Claude & Codex Integration

Send prompts directly to Claude CLI or Codex CLI. Stream responses in real-time with syntax highlighting.

Tamagotchi Pet

Track Food, Joy, Energy, and XP. Stats decay over time. Earn XP by running commands. Evolve through 5 stages.

Pet Battles

Challenge another player, wait for accept, then pick attack + defense zones. Tactical choices can beat raw level difference.

23 Achievements

Daily Quests

Social Leaderboard

Pet Marketplace

How it works

Up and running in 3 steps

No complex setup. No dependencies. Just clone, run, and code.

1

Install

Clone the repo and run the launch script. Swift compiles instantly on macOS -- no dependencies needed.

$ git clone ... $ ./run.sh ✓ Built!
2

Train specialization

Use Claude/Codex daily, add explicit facts with /train, and check growth in /training.

/train stake engine math /promptcoach /training
3

Publish and monetize

List your specialist pet on the marketplace, let others rent it, and build reputation around your strongest domain.

/rent publish 80 7 GameMathPro /market /rent my owner
