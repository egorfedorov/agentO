What Agent-O can do

A native macOS floating panel. Built with Swift + AppKit. No Electron, no Python, no bloat.

🤖

Claude & Codex Integration

Send prompts directly to Claude CLI or Codex CLI. Stream responses in real-time with syntax highlighting.

CORE
🎵

Tamagotchi Pet System

Feed, play, and rest your Agent-O. Stats decay over time. Running commands earns XP. Keep your pet happy!

FUN
🚀

Evolution & Leveling

Baby → Evolved → Epic → Mythic → Cosmic. Each stage unlocks new visual flair for your agent.

NEW
🏆

23 Achievements

Unlock achievements for milestones: commands run, commits, streaks, mini-games, time-based challenges.

NEW
🎮

Mini-Games

Number guessing and dev trivia. Win games to earn bonus XP and level up faster.

FUN
🍅

Pomodoro Timer

Built-in focus timer (25 min or 10 min). Break timer included. +40 XP per completed pomodoro.

NEW
🎨

Skins & Themes

4 detailed character skins (Robot, Cat, Skull, Clippy) and 5 color themes (Matrix, Cyberpunk, Sunset, Ocean, Hacker).

FUN
⌨

Global Hotkey

Cmd+Shift+O to show/hide from anywhere. Minimizes to a tiny floating icon. Menu bar integration.

CORE
📄

Drag & Drop Files

Drop any file onto the window to analyze it with Claude. Quick action buttons for commit, test, review.

CORE
📈

Git Integration

Auto-detects git repos. Shows branch and changes count. Quick commit, test, and code review buttons.

CORE
📋

Clipboard Analysis

Type !paste to analyze clipboard content with Claude. Perfect for quick code explanations.

NEW
🔔

macOS Notifications

Native notifications for achievements, pomodoro completion, and important events.

NEW
🌐

Instant Translation

Type "EN text" to translate to English, "RU text" for Russian. 18 languages. Auto-copied to clipboard.

NEW
👁

Clipboard Watcher

Agent-O monitors your clipboard. Auto-detects code and errors, suggests explain or fix. Smart assistant mode.

NEW
💾

Code Snippets

Save Claude responses as snippets. Search your personal knowledge base. Never lose a useful answer again.

NEW
🎴

Share Card

Export a beautiful SVG pet card with your level, stats, and achievements. Share on Twitter and Discord.

FUN
📸

Screenshot Analysis

Capture any area of your screen and Claude analyzes it. Errors, UI, code — just screenshot and ask.

NEW
🔍

AI Code Review

Type !diff and Claude reviews your git changes. Auto-generates commit messages from staged files.

NEW
💬

Multiple Chats

Switch between chat sessions. Keep different contexts for different projects. Never lose a conversation.

NEW

Choose your skin

4 unique ASCII characters with detailed art. Switch anytime with !skin command.
