4) Token Optimizer Plugin

Specialist Modes

Current direction is to keep pet learning real and personalized around your daily workflow.

  • Auto mode picks strongest domain from accumulated signals.
  • Manual mode lets owner lock specialist during a project sprint.
  • Profile is visible in listing description so renters know why to hire this pet.
  • Training loop ties prompt quality to economy outcomes.
  • Token optimizer keeps context useful while reducing average input size.
/specialist /specialist list /specialist auto /promptstats 7 /optimizer

Trust and Fairness Direction

Core product goal: valuable pets should come from real work quality, not fake stats.

  • Identity binding protects ownership and profile continuity.
  • Challenge/accept battle flow blocks instant spam fighting.
  • Rental economy rewards domain consistency over random leveling.
